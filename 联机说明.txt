王建文 大战 王精文 · 联机说明
========================================

【两个人怎么联机】

1) 房主 A
   - 双击「启动联机.bat」
   - 会弹出一个黑色窗口，里面写着类似：
         本机打开：   http://localhost:8080
         局域网/Radmin 地址：
             http://26.166.58.0:8080   <- Radmin VPN
   - 浏览器会自动打开游戏；如果没有，就手动打开 http://localhost:8080
   - 第一次运行时 Windows 可能弹出防火墙提示，请选「允许访问」

2) 对手 B
   - 确认 Radmin VPN 已连上房主的网络
   - 用浏览器打开房主给你的那条地址，例如 http://26.166.58.0:8080
   - 对手什么都不用安装，也不用开服务器

3) 开始对战
   - 两人都点首页的「联机对战」
   - A 点「创建房间」，屏幕中间会出现 4 位房间号（例如 6065）
   - A 把房间号报给 B
   - B 输入房间号，点「加入」
   - 两边都显示「对手已就位」后，由 A 点「开始对战」

【对战时】
   - 每人只能点自己那个角色：A 是左边王建文，B 是右边王精文
   - 血量、怒气、连击、大招画面都是实时同步的
   - 右上角显示「房间号 · 你的角色 · 延迟」
   - 一局结束后：A 点「再来一局」；B 也可以点「请求再战」，房主会自动开始
   - 中途想退出：连按两次 ESC

【如果直接双击 index.html 打开】
   进入「联机对战」后会多出一个「服务器地址」输入框：
       房主填：127.0.0.1:8080
       对手填：房主的Radmin IP:8080   例如 26.166.58.0:8080
   （更推荐双方都用浏览器打开房主打印的那个网址，就不用填地址了）

【常见问题】
   对手打不开网页 / 连不上
     1. 房主那个黑色窗口是否还开着
     2. Windows 防火墙是否放行了 Node.js
        控制面板 → Windows Defender 防火墙 → 允许应用通过防火墙
        → 找到 Node.js → 勾选「专用」
     3. 两边 Radmin 都在线吗？对手输的是 26.x.x.x 而不是 127.0.0.1
     4. 杀毒软件是否拦截了 Node.js 监听端口

   端口被占用
     先关掉占用 8080 的程序；服务器会自动尝试 8081、8082。
     也可以自己设置环境变量 PORT 再运行 server.js

   不想联机的时候
     直接双击 index.html 单机玩，功能完全不受影响

【文件说明】
   index.html     游戏本体（单机 / 联机都在里面）
   server.js      联机中继服务器，零依赖，只用 Node 内置模块
   启动联机.bat   双击启动服务器并自动打开浏览器
   assets\        两位角色的立绘
